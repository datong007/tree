# 产品定制系统 (Product Customization System)

## 项目概述
这是一个现代化的产品定制系统，支持多语言展示、3D模型预览和实时颜色定制功能。系统采用 Next.js 框架开发，结合了 Three.js 的 3D 渲染能力和 Tailwind CSS 的样式系统。

## 主要特性

### 1. 首页设计
- **多语言支持**：支持11种语言自动轮播展示
  - 中文
  - 英文
  - 日文
  - 韩文
  - 俄文
  - 波兰文
  - 德文
  - 西班牙文
  - 法文
  - 泰文
  - 马来西亚文

- **动态星空背景**：
  - 200颗动态移动的星星
  - 流畅的动画效果
  - 响应式设计

- **背景音乐**：
  - 可控制的背景音乐播放
  - 优雅的控制界面
  - 自动音量调节

### 2. 产品定制功能
- **3D模型预览**：
  - 实时旋转和缩放
  - 材质实时更新
  - 高清渲染

- **颜色定制**：
  - 支持潘通色号输入
  - 实时预览效果
  - 多部件独立定制

### 3. 用户界面
- **响应式设计**：
  - 适配多种设备尺寸
  - 流畅的过渡动画
  - 直观的操作界面

- **表单系统**：
  - 订单信息收集
  - 实时验证
  - 错误提示

## 技术栈
- **前端框架**：Next.js 13+
- **编程语言**：TypeScript
- **3D渲染**：Three.js
- **样式系统**：Tailwind CSS
- **状态管理**：React Hooks
- **版本控制**：Git
